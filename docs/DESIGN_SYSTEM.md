# Portfolio Design System

## 방향

현재 기본 방문자 화면은 `Mist` 테마입니다. 목표는 장식적인 웹 카드 모음이 아니라 흰 종이에 정리된 포트폴리오 인쇄물에 가까운 화면입니다. 콘텐츠의 위계는 그림자나 과한 색보다 타이포그래피, 규칙선, 여백과 작은 기하학 표식으로 만듭니다.

## 색과 재질

- 기본 바탕은 따뜻함이 과하지 않은 흰색 계열입니다.
- 종이 질감은 매우 옅게 유지하며 콘텐츠를 방해하는 노이즈는 사용하지 않습니다.
- 본문은 짙은 중성색, 보조 정보는 낮은 대비의 회색을 사용합니다.
- 포인트 컬러는 한 화면에서 한 계열만 사용합니다.
- 히어로의 포그는 무채색이어야 하며 배경색을 붉게 물들이지 않습니다.

## 타이포그래피

- 한국어 본문은 Gowun Batang 계열을 중심으로 사용합니다.
- 제목은 인쇄물의 표제처럼 보이되 지나치게 장식적인 캘리그래피는 사용하지 않습니다.
- 모바일 주요 섹션 제목은 `clamp(2.15rem, 9.4vw, 2.4rem)` 범위로 통일합니다.
- 모바일의 읽는 본문은 15–16px, 보조 메타 정보는 12–13px를 기준으로 합니다.
- 성과 목록은 번호와 본문의 두 열 구조를 유지하되 제목은 18px, 설명은 16px로 표시합니다. 본문 속 수치 강조는 과한 굵기 대신 얇은 밑줄을 사용합니다.
- 본문 줄높이는 1.5–1.7 범위를 유지합니다.
- 어드민에 저장된 명시적 줄바꿈은 넓은 화면에서 우선 보존합니다. 모바일에서는 오버플로를 막기 위해 필요한 경우에만 추가 줄바꿈을 허용합니다.

## 레이아웃과 여백

- 섹션은 공통 종이 여백과 동일한 콘텐츠 폭을 사용합니다.
- 상단선과 하단선 사이의 콘텐츠는 시각적으로 중앙에 놓이도록 같은 세로 패딩을 사용합니다.
- 목록의 번호, 제목, 본문은 정해진 그리드 열에 맞춥니다.
- 모바일에서는 한 열로 전환하되 번호와 본문의 시작선을 섹션마다 임의로 바꾸지 않습니다.
- 데스크톱에서 충분한 너비가 있으면 의도하지 않은 제목 줄바꿈을 만들지 않습니다.

## 히어로

- 높이는 모바일 브라우저 UI 변화에 안전하도록 `100dvh` 기준을 사용합니다.
- `PORTFOLIO` 제목은 모바일 상단과 하단 콘텐츠 사이의 시각적 중심에 둡니다.
- 포그는 원 하나처럼 보이지 않는 구름형 무채색 블러로 천천히 움직입니다.
- 선명하게 열리는 중심 영역은 제한적으로 유지하며 배경 전체가 색 덩어리처럼 보이지 않게 합니다.
- 통계 행은 번호, 라벨, 연결선, 값을 동일한 수직 중심에 맞춥니다.

## 커리어 저니

- 각 행은 번호, 연도, 회사, 역할과 현재 상태를 고정된 그리드에 배치합니다.
- 현재 상태는 `NOW` 텍스트 대신 연도 바로 아래의 10px 채움 사각형으로 표시합니다.
- 현재 표식과 연도는 같은 그리드 열과 같은 좌측 시작선을 사용합니다.
- 행 전체는 해당 업무 경험으로 이동하는 버튼이므로 키보드 포커스 표시를 유지합니다.

## 프로젝트와 경력

- 프로젝트 카드 호버 시 크기와 위치가 움직이지 않습니다.
- 모바일 프로젝트는 각 사례의 제목, 설명, 단계, 지표와 결과 사이를 선과 여백으로 명확히 구분합니다.
- 움직이는 기하학 장식은 삭제하지 않으며 콘텐츠와 겹치지 않는 지정 위치를 사용합니다.
- 경력 항목의 본문과 `OTHER TASKS` 목록은 같은 본문 리듬을 사용합니다.
- 원본 프로젝트, 경력, 교육 및 활동 내용은 스타일 수정 때문에 삭제하거나 축약하지 않습니다.
- 교육과 외부 활동을 묶는 마지막 상위 섹션 제목은 간결한 `Background`를 사용하고, 내부 소제목에서 `Education`과 `Activities`를 구분합니다.

## 장식과 인터랙션

- 이모지는 사용하지 않습니다.
- 별, 점, 십자, 클로버 등은 CSS로 만든 단순 기하학 기호만 사용합니다.
- 장식은 의미 콘텐츠보다 낮은 시각적 우선순위를 가져야 합니다.
- 도형은 한 섹션의 한쪽 모서리에 몰아넣지 않고 페이지의 바깥 여백에 낮은 밀도로 분산합니다.
- 히어로 도형은 제목을 직접 가리지 않는 비대칭 위치로 구성하며, 모바일에서는 장식 수를 줄입니다.
- 호버는 색, 선 굵기 또는 미세한 텍스트 이동으로 표현하며 레이아웃을 흔들지 않습니다.
- 위치가 바뀌는 호버 효과는 `(hover: hover) and (pointer: fine)` 환경에서만 허용합니다. 터치 환경에서는 탭 후 남는 hover 상태가 텍스트 정렬을 바꾸지 않아야 합니다.
- `prefers-reduced-motion` 환경에서는 반복 이동과 진입 모션을 줄입니다.

## 반응형 점검 기준

- 모바일: 320px, 360px, 390px, 430px
- 태블릿: 768px, 1024px
- 데스크톱: 1280px, 1440px 이상

각 크기에서 다음을 확인합니다.

1. 가로 스크롤이 생기지 않는가
2. 제목이 충분한 공간에서도 불필요하게 줄바꿈되지 않는가
3. 본문이 15px 미만으로 작아지지 않는가
4. 섹션 시작선과 콘텐츠 시작선이 일관적인가
5. 규칙선이 이중으로 보이거나 중간에 끊기지 않는가
6. 장식이 본문과 겹치지 않는가
7. 포커스, 호버와 클릭 상태가 레이아웃을 움직이지 않는가

## 변경 절차

시각 변경 후 `npm run check`를 실행합니다. 모바일과 데스크톱을 모두 확인한 뒤, 지속적으로 유지해야 할 규칙은 이 문서에 추가하고 사용자에게 보이는 변경은 `CHANGELOG.md`에 기록합니다.

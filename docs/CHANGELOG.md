# Change Log

사용자에게 보이는 디자인과 동작 변경을 기록합니다. 내부 리팩터링만 있는 경우는 생략할 수 있습니다.

## 2026-09-26

- 관리자 화면에 30분 유휴 자동 로그아웃, 만료 5분 전 경고와 탭 간 로그아웃 동기화를 추가했습니다.
- JSON 가져오기에 용량·구조·위험 키 검증과 적용 전 변경 대상 미리보기를 추가했습니다.
- 이미지 업로드에서 허용 MIME, 용량과 해상도를 저장 전에 검증하고 안전한 확장자를 사용하도록 강화했습니다.
- 클라이언트 오류 수집에서 토큰·인증 헤더·키를 마스킹하고 이벤트 식별자와 발생 시각을 기록하도록 개선했습니다.
- Firestore·Storage 권한 계약과 번들 예산을 CI에서 회귀 검사하고 운영 롤백·복구 런북을 추가했습니다.
- 테마 가이드 7종과 가이드 허브를 프로덕션 다중 페이지 산출물에 포함해, 어드민의 `디자인 시스템 보기`가 운영 환경에서도 각 테마 가이드를 404 없이 엽니다.
- 어드민 반응형 가이드의 모바일 미리보기를 항상 열린 메뉴 그림에서 실제 `접속 로그` 페이지로 바꾸고, 상단 메뉴 버튼으로 페이지와 전체 메뉴 상태를 직접 전환해 실제 구현과 같은 흐름을 검증하도록 수정했습니다.
- Mist는 시스템 커서를 정확한 조준점으로 항상 유지하고, 회전 기호와 행동 라벨은 포인터 우하단의 보조 표시로만 동작하게 고정했습니다. 경력 상세와 프로젝트 단계 탭의 읽기 크기도 본문 역할에 맞게 상향했습니다.
- 실제 테마 미리보기 툴바를 가이드 표본과 같은 `제목 → 테마·화면·폭 라벨 → 컨트롤` 구조로 맞췄습니다.
- 7개 프론트 테마 디자인 시스템의 헤더를 공통 컴포넌트로 통일하고, 어드민의 각 테마 카드에서 해당 테마 가이드를 새 탭으로 직접 열 수 있게 연결했습니다. 가이드 헤더에서는 테마 간 이동과 검토 종료를 동일한 44px 조작 규칙으로 제공합니다.
- 모바일 어드민 메뉴를 두 열 축약 목록에서 전체 화면 단일 열 메뉴로 교체했습니다. 모든 메뉴명과 번호를 온전히 표시하고 현재 위치, 그룹 구분, 하단 PDF·로그아웃 행동을 명확히 했습니다.
- 방문자 테마 설정에서 어드민 색상 모드 안내를 제거하고, 실제로 선택할 수 없는 `토큰별 테마`는 버튼형 카드 대신 토큰 관리 위치를 알리는 일반 안내로 변경했습니다.
- 실제 방문자 화면 위의 테마 미리보기 툴바가 선택한 방문자 테마에 물들지 않고 저장된 어드민 라이트·다크 모드를 따르도록 수정했습니다.
- 테마 설정의 모든 테마 카드에 해당 테마의 `디자인 시스템 보기` 버튼을 연결 대기 상태로 추가해, 연결 후에는 카드를 기준으로 테마별 가이드를 선택할 수 있게 준비했습니다.
- 프로젝트 표현 방식 선택에 ‘현재 편집 중’을 명시하고 선택기와 저장·JSON 액션 바를 하나의 작업 묶음으로 연결해, 선택 결과가 아래 편집 범위를 바꾼다는 관계를 클릭 전에도 알 수 있게 했습니다.
- 배지·스킬 분류 화면의 중복 패널 제목과 설명을 제거해 페이지 제목 다음에 실제 사용처와 편집 목록이 바로 시작되도록 했으며, 단일 패널은 제목을 반복하지 않고 병렬 패널이 둘 이상일 때만 서로 다른 작업 범위를 서브 제목으로 표시하는 정보 위계 규칙을 디자인 시스템과 문서에 동기화했습니다.
- 넓은 화면의 안내 문장에 남아 있던 임의 폭 제한을 제거해 마지막 한두 글자만 다음 줄로 고립되지 않게 했습니다.
- 테마 화면에서 적용 대상 탭을 유일한 제목으로 유지하고 중복 제목과 상단 전체 미리보기를 제거했으며, 미리보기는 각 테마 카드 하단에만 남겼습니다.
- 접힌 경력 요약 행의 회사명·직함·프로젝트 수·기간 열을 공통 고정 트랙으로 바꿔 내용 길이에 따라 열 시작선이 움직이지 않게 했습니다.
- 핵심 성과뿐 아니라 학력·활동·스킬·분류·프로젝트 성과의 반복 편집 행을 위쪽 기준선으로 통일하고, 마지막 관련 필드와 삭제를 하나의 관리 그룹으로 묶었습니다. 실제 컴포넌트 표본과 같은 규칙을 디자인 시스템 화면과 문서에 동일하게 추가했으며 자동 동기화 테스트로 문구 이탈을 막았습니다.
- 실제 1280–1440px 브라우저에서 축소판처럼 보이던 문제를 해결하기 위해 어드민과 디자인 시스템의 최소 표시 크기를 13px로 올리고 Page 32/40, Section 18/28, Control 15/22 역할 체계로 재정의했습니다.
- 운영 대시보드에서 작게 남아 있던 상태 안내, 지표 라벨, 패널 설명, 그래프 범례·축, 빠른 작업과 사이드바 글자를 13–16px 역할 체계로 다시 올렸습니다.
- 운영 화면의 가독성을 위해 어드민 타이포그래피를 Page 32/40, Body 16/26, Control 15/22, Support 14/22, Micro 13/20 역할 체계로 상향하고 사이드바·대시보드·폼·표·그래프·토큰·로그인에 동일하게 적용했습니다.
- Vercel 업로드 제외 목록에서 `public/assets`를 제거해 캠페인 샘플 이미지 4종이 운영 배포에서도 404 없이 제공되도록 수정했습니다.
- 어드민의 primary·link·사이드바 버튼 hover를 역할 토큰 기반으로 통일해 라이트·다크에서 글자와 배경 대비가 사라지지 않도록 했습니다.
- 페이지 바로가기와 맨 위 이동 버튼을 44px 고대비 조작부로 묶고 safe area, 열린 목록 높이와 모바일 가장자리 규칙을 추가했습니다.
- 프로젝트, 경력·학력·활동, 스킬, 성과, 커리어 저니, 배지 분류와 이미지 연결 해제를 포함한 모든 편집 삭제에 대상명이 있는 확인 다이얼로그를 적용했습니다.
- 디자인 시스템과 반복 방지 작업 지침에 버튼 전체 상태 대비, 플로팅 조작부, 모든 삭제·연결 해제 확인 규칙을 추가했습니다.
- 프로젝트를 `PM`과 `디자인`으로 나누던 어드민 메뉴를 하나의 프로젝트 영역으로 통합하고, 구조형·아카이브형을 직무 분류가 아닌 확장 가능한 표현 방식으로 변경했습니다. 기존 저장 키와 데이터는 그대로 유지합니다.
- 모바일 상단의 테마 전환과 포트폴리오 보기를 44px 이상 아이콘·라벨 버튼으로 바꾸고, 로그아웃은 펼친 메뉴 안의 전체 폭 버튼으로 옮겨 오조작을 줄였습니다.
- 생성된 캠페인 이미지 4종을 아카이브형 더미 프로젝트의 대표 이미지와 갤러리 데이터에 연결하고 대체 텍스트·캡션을 함께 추가했습니다.
- 테마 편집 상단의 중복된 전체 화면 미리보기 버튼을 제거하고, 저장 계열은 왼쪽·JSON 가져오기와 내보내기는 오른쪽에 배치해 공통 액션 바 규칙을 적용했습니다.
- 히어로, 접속 화면과 연락처의 전체 폭 단일 열 폼을 의미별 패널과 반응형 2열 편집 구조로 교체했습니다.
- 경력·학력·활동을 공통 Collection 패널, compact 행, 표준 빈 상태로 통일하고 경력 프로젝트의 master/detail 편집을 유지했습니다.
- 경력 기간 입력을 별도 전체 행으로 옮겨 시작월·종료월·현재 선택이 잘리지 않도록 했습니다.
- 커리어 저니 편집기에서 중복 테마 안내와 팔레트를 제거하고 정렬된 compact 편집 표로 변경했습니다. 저장된 방문자 테마는 공개 화면에 계속 자동 적용됩니다.
- `분류·선택지`를 `배지·스킬 분류`로 명확히 바꾸고 프로젝트 배지 유형, 소개 스킬 분류, 테마 색상이라는 실제 사용 위치를 편집 화면에 표시했습니다.
- 변경 이력의 빈 상태와 오류 상태를 아이콘·이유·설명·행동이 한 묶음으로 보이는 세로형 센터 정렬로 통일했습니다.

- 기존 PM 프로젝트를 보존하면서 이미지 중심 디자인 프로젝트 영역을 추가했습니다.

- 디자인 상세 페이지를 문제 정의, IA/User Flow, 솔루션, 검증, 디자인 시스템의 5단계 구조로 구성했습니다.

- 모바일 상세 하단의 이전·다음·아카이브 탐색과 푸터를 안정적인 한 열 구조로 정리했습니다.
- 커리어 저니의 현재 상태를 단독 사각형 대신 회전하는 반짝이 기호와 `NOW` 조합으로 표시했습니다.
- 프로젝트 상세 Brief의 불필요한 번호 열을 제거하고 제목과 본문을 가까운 2열로 재정렬했으며, 과도한 상하 여백을 줄였습니다.
- 화면마다 달랐던 제목 색상을 다크 차콜로 통일하고, 토프 색상은 라벨·번호·연도·링크·현재 상태에만 사용하도록 색상 위계를 정리했습니다.
- 흩어진 모바일·태블릿 예외를 하나의 반응형 계약으로 통합하고 섹션 여백, 제목 간격, 경력 그리드, 상세 페이지와 아카이브의 축소 규칙을 320–1179px 구간에서 재정의했습니다.
- 프로젝트 상세의 원형 닫기 버튼을 우측 상단 `Close ×` 링크로 바꾸고 메인 복귀 동작을 유지했습니다.
- Brief를 번호형 본문과 구분되는 도입 띠로 재설계하고 모바일 한 열, 태블릿·데스크톱 두 열 규칙을 적용했습니다.
- 프로젝트 상세와 메인이 같은 공통 푸터를 사용하도록 정렬 규칙을 통일하고 모바일·태블릿의 연락처와 상단 이동 순서를 보정했습니다.
- 로그인 화면의 이메일과 요청 안내 문구를 하나의 연락 채널 묶음으로 배치해 문구가 떨어져 보이지 않게 했습니다.
- 디자인 프로젝트 갤러리에 다중 이미지 등록, 위·아래 순서 변경, 프론트 이전·다음 및 썸네일 탐색을 추가했습니다.
- 디자인 전체 아카이브에도 메인·상세 페이지와 동일한 공통 푸터를 연결했습니다.
- 프로젝트 그룹 제목의 이동 표시를 실제 업무 경험으로 스크롤하는 버튼으로 복구하고 어드민에서 연결 대상을 선택할 수 있게 했습니다.
- 노란 프로젝트 영역의 차가운 회색선을 제거하고 제목·본문·메타·행동·구분선의 역할별 색상 토큰을 적용했습니다.

- 콘텐츠 원문을 삭제하지 않습니다.
- 이모지를 사용하지 않습니다.

- 프로덕션 배포 후 실사이트의 최신 자산 반영 여부를 확인합니다.

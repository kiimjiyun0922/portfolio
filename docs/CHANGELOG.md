# Change Log

사용자에게 보이는 디자인과 동작 변경을 기록합니다. 내부 리팩터링만 있는 경우는 생략할 수 있습니다.

## 2026-09-25

- 기존 PM 프로젝트를 보존하면서 이미지 중심 디자인 프로젝트 영역을 추가했습니다.
- 공개 디자인 프로젝트를 모아 보는 `/projects` 아카이브와 `/projects/:slug` 상세 페이지를 추가했습니다.
- 디자인 상세 페이지를 문제 정의, IA/User Flow, 솔루션, 검증, 디자인 시스템의 5단계 구조로 구성했습니다.
- 어드민 프로젝트 편집기에 디자인 프로젝트의 공개·추천 설정, 대표 이미지, 상세 본문, 갤러리와 아카이브 노출 기준을 추가했습니다.
- 실제 수치로 오해되지 않도록 `Sample Project`로 표시한 더미 디자인 프로젝트 4개와 샘플 이미지를 추가했습니다.
- 히어로의 태그라인과 헤드라인을 `PORTFOLIO` 가까이 이동해 직무와 전문 영역을 먼저 읽을 수 있게 했습니다.
- 모바일 프로젝트에 최대 3개 핵심 지표를 먼저 보여주는 `At a glance` 요약을 추가했습니다.
- 모바일 성과 목록의 제목을 18px, 본문을 16px로 올리고 강조 수치의 검은 굵기를 얇은 밑줄 표현으로 정리했습니다.
- 모바일의 프로젝트 탭·배지·지표 라벨, 경력 메타 정보, 저니 역할명과 푸터처럼 지나치게 작던 글자를 12–14px 범위로 보정했습니다.
- 마지막 섹션 제목을 `Education & Activity`에서 `Background`로 줄였습니다.
- 모바일에서 커리어 저니를 탭한 뒤 회사명이 우측으로 밀리는 잔류 hover 동작을 제거했습니다.
- 프로젝트 헤더 한쪽에 몰려 있던 장식을 섹션의 좌우와 페이지 중간으로 분산했습니다.
- 히어로의 별, 점, 십자, 클로버 위치를 비대칭으로 다시 구성했습니다.
- 소개, 커리어 저니, 성과, 경력, 교육 섹션의 바깥 여백에 작은 도형을 추가했습니다.
- 커리어 저니의 현재 상태를 `NOW` 텍스트에서 연도 아래의 채움 사각형으로 변경했습니다.
- 모바일 주요 섹션 제목 크기를 하나의 체계로 통일했습니다.
- 모바일 소개와 프로젝트 본문을 16px, 경력·교육·성과 본문을 15px로 조정했습니다.
- 작은 번호, 연도, 카테고리와 메타 정보는 12–13px 체계를 유지했습니다.
- 모바일 프로젝트 장식을 삭제하지 않고 지정 위치로 복원했습니다.
- 모바일 프로젝트 사례 사이의 구분선과 여백을 강화했습니다.
- 히어로 포그를 무채색 구름 형태로 조정하고 선명 영역과 모바일 위치를 보정했습니다.
- 모바일 경력 목록의 줄간격, 항목 간격과 시작선을 정리했습니다.
- 모바일 디자인 프로젝트 인덱스를 잘리는 가로 목록에서 전체 제목이 보이는 세로 목록으로 변경했습니다.
- 디자인 프로젝트 대표 이미지를 모바일에서도 3:2 비율로 유지해 정사각형처럼 과도하게 잘리지 않게 했습니다.
- 아카이브와 상세 페이지의 모바일 메타 정보를 최소 12px로 올렸습니다.
- 모바일에서 스크롤 진입 전 콘텐츠가 흐리거나 빈 영역처럼 보이지 않도록 섹션 진입 모션을 정적 표시로 전환했습니다.
- 기존 추상 샘플 이미지를 제품 출시, 문화 행사, 리테일, B2B 캠페인으로 구성한 미니멀 마케팅 작업물 4종으로 교체했습니다.
- 실서비스에 저장된 디자인 프로젝트 목록이 비어 있거나 구형 샘플만 포함한 경우 새 캠페인 샘플을 표시하도록 데이터 마이그레이션을 보완했습니다. 사용자가 추가한 프로젝트는 유지합니다.
- 프로젝트 상세 하단에 메인 포트폴리오로 돌아가는 링크와 상단 이동을 추가했습니다.
- 상세의 Brief를 다른 케이스 스터디 항목과 같은 번호·제목·본문 그리드로 정렬했습니다.
- 모바일 상세 하단의 이전·다음·아카이브 탐색과 푸터를 안정적인 한 열 구조로 정리했습니다.
- 커리어 저니의 현재 상태를 단독 사각형 대신 회전하는 반짝이 기호와 `NOW` 조합으로 표시했습니다.
- 프로젝트 상세 Brief의 불필요한 번호 열을 제거하고 제목과 본문을 가까운 2열로 재정렬했으며, 과도한 상하 여백을 줄였습니다.
- 화면마다 달랐던 제목 색상을 다크 차콜로 통일하고, 토프 색상은 라벨·번호·연도·링크·현재 상태에만 사용하도록 색상 위계를 정리했습니다.
- 흩어진 모바일·태블릿 예외를 하나의 반응형 계약으로 통합하고 섹션 여백, 제목 간격, 경력 그리드, 상세 페이지와 아카이브의 축소 규칙을 320–1179px 구간에서 재정의했습니다.
- 프로젝트 상세의 원형 닫기 버튼을 우측 상단 `Close ×` 링크로 바꾸고 메인 복귀 동작을 유지했습니다.
- Brief를 번호형 본문과 구분되는 도입 띠로 재설계하고 모바일 한 열, 태블릿·데스크톱 두 열 규칙을 적용했습니다.
- 프로젝트 상세와 메인이 같은 공통 푸터를 사용하도록 정렬 규칙을 통일하고 모바일·태블릿의 연락처와 상단 이동 순서를 보정했습니다.
- 로그인 화면의 이메일과 요청 안내 문구를 하나의 연락 채널 묶음으로 배치해 문구가 떨어져 보이지 않게 했습니다.
- 디자인 프로젝트 갤러리에 다중 이미지 등록, 위·아래 순서 변경, 프론트 이전·다음 및 썸네일 탐색을 추가했습니다.
- 디자인 전체 아카이브에도 메인·상세 페이지와 동일한 공통 푸터를 연결했습니다.
- 프로젝트 그룹 제목의 이동 표시를 실제 업무 경험으로 스크롤하는 버튼으로 복구하고 어드민에서 연결 대상을 선택할 수 있게 했습니다.
- 노란 프로젝트 영역의 차가운 회색선을 제거하고 제목·본문·메타·행동·구분선의 역할별 색상 토큰을 적용했습니다.

## 유지 원칙

- 콘텐츠 원문을 삭제하지 않습니다.
- 이모지를 사용하지 않습니다.
- 반응형 변경은 모바일, 태블릿, 데스크톱을 함께 확인합니다.
- 프로덕션 배포 후 실사이트의 최신 자산 반영 여부를 확인합니다.
